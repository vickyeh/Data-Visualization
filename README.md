#Data Visualization

It is a course in CSE at University of Washington. In this class, we learn to use Observable Notebook to visualize and 
illustrate the cardiovascular system of the human body and the different heart problems associated with it. 
There will be two different aspects of our project: Visual diagrams detailing information about different heart diseases, and interactive charts about heart diseases in general.
We intend to make the project interactive by allowing the user to click on different labels in the diagram and select different parameters to read about their causes, epidemiology, impact by demographics, financial costs, complication data, and other useful information in our separate charts. 
So far for this milestone, we have examples of what data we want to display and what information we want to provide for the diagrams.
